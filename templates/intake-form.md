# 阳宅风水问诊单（intake-form）

> **为什么有这张单**：AI 没有眼睛，房屋信息全靠你输入；而口语描述结构化程度低（一句"朝南"
> 至少有三种坐向解释），AI 从描述里提取还会叠加理解偏差、且无法自己复核。所以反向设计——
> 从分析报告需要的**每个结论**反推出**必填字段**（每个字段都标了"→ 决定报告里的什么"），
> 你只需对空填数，不必组织语言。
>
> **怎么用**：
> - 信息基本空白 → 直接复制下面 A 部分填写回传（B/C 有则填，无则跳过）
> - 已经给过一些描述/户型图 → AI 会把已知项**预填**进本单回显，你只需确认或纠正，再补空
> - 单点问答（只问一件事）→ 只填相关条目即可
>
> **填写原则**：不知道就写"不知道"，**不要猜**——每项都给了降级路径，猜错一个数比缺一个数糟得多。

---

## A. 必填五项

### ① 建成年份 →（决定宅运：七运/八运/九运，全盘由此而定）

- 本楼建成年份：______ 年（大约 ______—______ 之间也可）
- 不知进入住/装修年份：______ 年（AI 会声明跨运争议）

> 不知道怎么办：问物业或中介"这栋楼哪年交付的"；再不知道就填入住年份。
> 为什么：1984–2003 七运 / 2004–2023 八运 / 2024 立春后九运，运不同则飞星全盘不同。

### ② 坐向 →（决定玄空排盘与格局判定，全 skill 最敏感的一个数）

先分清两个词：
- **向** = 站在屋里面朝屋外的自然方向（阳台/主采光面朝哪，"朝南的房"就是向南）
- **坐** = 向的正相反方向（背靠的那面墙）

按 a→d 顺序填，能填几个填几个：

- a. 手机指南针度数：面向屋外测得 ______°（在 ______ 处测的：大门内 / 阳台 / 主窗边）
  - 站法：**站在大门内背靠门、面朝屋外**读数（或到屋外离墙 3–5 米、与墙面平行处测）
  - 测量要点：离钢筋混凝土墙柱 1.5 米以上、远离电器与金属柜；取下磁吸手机壳、手表、钥匙串；**换 3 个位置各测一次，报 3 个数**（____° / ____° / ____°）
- b. 入户门朝向：门朝 ______ 开（如"门朝东开"）
- c. 阳台 / 主采光面朝向：______
- d. 楼栋整体朝向（看小区地图/沙盘，楼体正面朝 ______）

> 不知道怎么办：至少给 c；连方向感都没有 → 告诉 AI 楼盘名称+城市，AI 给查询思路。
> 精度警告：正向与替卦的分界约在 ±4.5°（另有流派以 3° 为界），而手机指南针误差可达 10–20°，
> **只能作初筛**——a 项请务必测 3 次比对；指针乱转说明该处有强电磁干扰，换位置再测。
> 说明：屋内物品"落宫"判定由 AI 按立极点（方正户型取对角线交点，缺角户型割补后取心）计算，
> **不需要你逐个量**；床向、灶口等房内朝向由 AI 按"房间中心"小太极处理，你只需在④里写清房间位置。

### ③ 命主 →（决定命卦、东西四命、宅命相配、文昌位、日课相主）

| 称呼 | 出生日期（公历） | 性别 | 备注 |
|---|---|---|---|
| 例：本人 | 1990-05-21 | 女 | |
| | | | |

> 不知道怎么办：生日必须**给到日**（只给年份时 AI 不做立春分界并会提示）；公历/阳历要分清，
> 阴历生日先换算。出生在 2 月 3–5 日（立春）前后的务必说明，命卦可能跨年。
> 为什么：命卦由出生年（立春分界）+性别决定，男女算法不同，缺性别 AI 只能按男命猜。

### ④ 户型布局 →（决定缺角、中宫厨厕、门冲、门主灶、流年五黄二黑落在哪个房间）

方法一（推荐）：发户型图照片或文字描述，AI 会代填下表回显请你确认。
- 拍图要点：整图无遮挡、光线均匀；**图上有尺寸/面积数字的开间标注请一并拍清楚或抄录**（AI 用它量化缺角，不靠目测）
- 图向说明：图上若有指北针请注明；没有的话告诉 AI 你判断图向的依据（如"我家阳台在这头"）。**图的上边不一定是北**，AI 会先定图向再归宫，并把判定结果回显请你确认
方法二：自己填。把户型图按"上北下南"摆正（可用手机指南针校准），把各功能区填进对应方位格
（一格可写多间，如"主卧+书房"；没有的方位写"无"）：

| 西北（乾） | 北（坎） | 东北（艮） |
|---|---|---|
|  |  |  |
| **西（兑）** | **中宫** | **东（震）** |
|  |  |  |
| **西南（坤）** | **南（离）** | **东南（巽）** |
|  |  |  |

需覆盖的名称：大门、客厅、主卧、次卧、厨房、卫生间、阳台、书房（或其他功能区）。
不会摆正户型图时的偷懒法：站在屋中心面朝大门，告诉 AI"大门在我 ____ 方"，AI 可代为推算全盘。

> 注意：AI 排盘输出的九宫图是**上南下北**的传统罗盘排法，与本格（上北下南）相反，属正常现象。
