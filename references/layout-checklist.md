# 户型布局核查清单

用户给出户型图（图片或文字描述）后，先做"宫位归位"再逐项核查。

## 一、户型图归宫方法

1. 找户型的**几何中心**（不规则户型取近似重心；缺角大的以可用区域重心估计）。
2. 令图纸的坐向与罗盘方位对齐（坐向度数已知时，直接按度数把 24 山/八宫覆盖到平面图上）。
3. 每个房间按其主体面积落宫；跨宫的房间记主要落宫+次要落宫。
4. 输出一张"房间 × 宫位"清单（脚本 `all --house house.json` 可自动完成），再逐项核查下列规则。

## 二、结构硬伤（与飞星无关，优先级最高）

| 项目 | 判定 | 影响 |
|---|---|---|
| 缺角 | 某宫缺失面积超过该宫的约 1/3（凸入不算，凹陷算缺） | 对应家人与身体受损：乾(父/首)、坤(母/腹)、震(长男/足)、巽(长女/股)、坎(中男/耳)、离(中女/目)、艮(少男/手)、兑(少女/口)——身体部位依《说卦传》，所配脏腑诸书略异，取通行口径。现代户型缺角普遍，缺角<1/3 只作提示 |
| 中宫为厨房 | "火烧心" | 传统大忌：火在中央，主心脏血液、家人烦躁 |
| 中宫为厕所 | "中央受污" | 大忌：主气脉受污，健康与财运俱损 |
| 中宫为楼梯 | 气流搅动中宫 | 中宫宜静，楼梯居中作提示 |
| 开门见灶 | 入户门直线可见灶台 | "财库外露"，主漏财 |
| 开门见厕 | 入户门直线可见卫生间门 | 污口煞，主健康与口碑受损 |
| 穿堂煞 | 大门直对阳台/大窗，一线贯通 | "前通后通，人财两空"，气不聚；可用玄关/屏风化解 |
| 门冲门 | 两门正对（尤其厕门对床门、厨门对大门） | 气口相冲，相对的用途互扰 |
| 横梁压顶 | 床、沙发、书桌、灶正上方有梁 | 所对应之人压力、健康受损；装修吊顶或移位化解 |
| 灶厨居中 | 厨房在全屋中部 | 与火烧心同论 |
| 卫生间改卧室 | 上下层皆为厕的夹层卧室 | 湿气与气脉受污，作显著提示 |

## 三、八宅门主灶核查（用 bazhai-dayou.md 的矩阵）

对每个命主逐项判定：门、主卧、灶台落宫为何星（宅卦与命卦各一列）。宜忌：
- 门：生气/延年/天医为佳，伏位可用；五鬼/绝命开门为重忌。
- 主卧：生气（利事业丁财）、延年（利婚姻）、天医（利健康）皆宜；绝命/五鬼方长期安床为重忌。
- 灶：宜压凶（祸害/六煞/五鬼/绝命）；灶口朝吉。
- 卫生间：宜压凶；压生气/天医/伏位为忌（"吉方受污"）。

## 四、玄空逐宫核查（用 xuankong-feixing.md 的盘面）

- **开门/窗/阳台**宜在旺向星所在宫（生旺之气入);忌在衰死向星宫（纳衰气）。
- **主卧**宜在旺山星宫或山星生旺之宫；忌山向星 2·5、2·3、6·7、7·9 之宫长期坐卧。
- **厨房**：宜落衰死向星之宫（以火制之，须灶口配合）；忌落旺向星宫（火烧财气）；2·5 宫作厨房有"火生土旺灾"之嫌，作提示并建议化泄（金属/白色调为民俗常用）。
- **卫生间**：落衰死之宫反可"以污压凶"；忌在当旺向星宫（泄财气）。
- **书桌/儿童房**：取山向星 1·4、1·6 宫，或流年四绿、一白所在宫（见 liunian-feixing.md）。
- **财位**：当运向星落宫为"真财位"，宜聚气（忌穿、忌污、忌压）；明财位（入门对角线交点）作辅助参考。

## 五、常见细化项

- 床头：靠实墙、不朝门、不贴窗、不在梁下；朝向可取命卦吉方（生气/延年/天医）。
- 镜子：不对床、不对灶、不对大门。
- 阳台：为现代住宅主要纳气口，按"向"论；堆杂物影响纳气。
- 鞋柜/玄关：进门见穿堂时用玄关遮挡为第一化解。
- 鱼缸/水景：放在旺向星宫或当运向星宫可催财；放错宫位（衰死向星）反动煞；流年五黄二黑方忌放（动水引动）。
- 空调/冰箱/洗衣机（动气之物）：类比"动水"，宜在向星生旺宫；避免在流年五黄、二黑方长期运转。
- 床头靠厕：卧室床头所靠的墙**另一面是卫生间**→湿气与管道动水贴头，不宜长住，换床位或加防潮隔层。
- 厕占财位：卫生间占向星旺位（明财位/当运旺向星宫）→保持洁净干燥、通风、使用率尽量低，不宜再放大水景催财。
- 厨厕门相对：厨房门与卫生间门正对→水火相冲，错开门向或常关其一、加门帘缓冲。

## 六、输出格式要求

核查结果分三级呈现：
- ✅ 合理（符合规则）；
- ⚠ 可优化（有瑕疵，给低成本调整建议）；
- ❌ 硬伤（明确违背规则，给化解方案并建议装修时整改）。

每一项判定都要写明依据（哪条规则、哪个星、哪个方位），不允许无依据的吉凶断语；化解建议注明"民俗传统做法，供参考"。
