# 日课择吉（玄空紫白 + 建除 + 通用宜忌）

> 择日体系庞大（正体五行造命、董公择日、奇门择日等均不在本 skill 范围）。本模块覆盖**入宅/搬家、动土装修、开业安床**等家居场景最常用的确定性方法，全部由 `scripts/fengshui.py riche` 计算，四柱与节气需 sxtwl。

## 一、紫白四盘（年月日时入中星）

1. **年星**：A=(2027−年)%9（0 作 9），立春换年。2024 三碧、2026 一白。
2. **月星**（月紫白起例诀：子午卯酉八白起，寅申巳亥二黑求，辰戌丑未五黄中）：
   - 子午卯酉年正月（寅月）起八白；寅申巳亥年正月起二黑；辰戌丑未年正月起五黄；
   - 逐月递减一位；以**节气月**交接（sxtwl 月柱）。
3. **日星**（日家白法不难求，二十四气六宫周。冬至雨水及谷雨，阳顺一七四中游；夏至处暑霜降后，九三六星逆行求）：
   - 冬至、雨水、谷雨后**第一个甲子日**分别起一白、七赤、四绿，逐日**顺**行；
   - 夏至、处暑、霜降后第一个甲子日分别起九紫、三碧、六白，逐日**逆**行；
   - 元与元之间的空档日沿用前元续排（脚本已处理）。
   - 该日星入中，冬至后顺飞、夏至后逆飞成盘。
4. **时星**（按日支分组起例）：
   - 阳遁（冬至后）顺行：子午卯酉日子时起一白；辰戌丑未日子时起四绿；寅申巳亥日子时起七赤；
   - 阴遁（夏至后）逆行：起九紫、六白、三碧；
   - ⚠ 资料源（福山堂）原文"冬至后辰戌丑未日子时七赤"为**笔误**，其后"丑五黄、寅六白、卯七赤"及夏至后镜像（起六白逆行）均证明应为**四绿**，脚本按修正值实现。
   - 时支：子时 23–01，每时辰两小时；该星入中顺/逆飞成盘。

**用盘原则**：日课紫白盘与宅运盘参看——当年月日时的旺星飞到坐山、向首、大门、主卧为得用；五黄、二黑所到之方忌动土动水。择日以**日为主、年月为辅、时辰引之**（"年月不如日，日不如时"）。

## 二、十二建除与黄黑道

月建（节气月支）起「建」，顺数至日支得十二神：

> 建满平收黑，除危定执黄，成开皆可用，破闭不相当。

| 神 | 级 | 通用宜忌（民俗） |
|---|---|---|
| 建 | 黑 | 宜出行赴任；忌动土开仓 |
| 除 | 黄 | 宜除旧布新、打扫、治病；旧宅翻新始工可用 |
| 满 | 黑 | 丰盈之日，宜祭祀祈福；忌入宅、服药 |
| 平 | 黑 | 平常之日，诸事平平 |
| 定 | 黄 | 宜入宅、安床、订约 |
| 执 | 黄 | 宜执守、捕捉；不宜迁移 |
| 破 | 凶 | **月破日**，大事勿用 |
| 危 | 黄 | 宜安床；忌登高行险 |
| 成 | 黄 | 宜入宅、开市、嫁娶（成日尤吉） |
| 收 | 黑 | 宜收藏纳财；忌开市出行 |
| 开 | 黄 | 宜开市、入宅、动土（开日吉） |
| 闭 | 凶 | 宜安葬塞穴；忌开市、入宅、动土 |

（各神细宜忌诸书略异，上表为通行口径，标注民俗参考。）

## 三、硬性避忌（脚本自动判定）

- **月破日**：日支冲月建（即建除之"破"）——大事勿用。
- **岁破日**：日支冲太岁年支——大事勿用。
- **日冲**：日支对冲之生肖（家中该属相者此日大事尽量回避）。
- **四离四绝**：二分二至前一日为四离，四立前一日为四绝——诸事不宜，尤其动土、搬迁。
- 入宅常用吉神：**成、定、开**（再参 除/危），配合不冲宅主年支、非月破岁破。

## 五、正体五行造命（补龙扶山相主）

正体五行（正五行）择日法把所选日课的四柱当作一件"事情之命"来造：**一补龙、二扶山、三相主**。阳宅以坐山代龙，脚本在 `riche --sitting` 时自动输出：

1. **扶山（含补龙）**：坐山取罗盘**正五行**（亥壬子癸水、寅甲卯乙巽木、巳丙午丁火、申庚酉辛乾金、辰戌丑未坤艮土）。统计课八字（四柱干支逐字）与坐山的生扶/比和/泄/耗/克字数：生扶比和多且无克山为"扶山得力"。
2. **冲山**：课中地支冲坐山地支（子山忌午…）、干山见对冲干（甲山忌庚…）——**大忌，此课不可用**。四维山（乾坤艮巽）无支冲，忌对宫山向相冲。
3. **相主**（每位主命，按出生年月日取年柱，立春分界）：
   - **冲命**：课支冲主命年支——大忌不可用；
   - **纳音生克**：六十甲子纳音（甲子乙丑海中金…壬戌癸亥大海水），课柱纳音生主命纳音/比和为吉，克主命为凶；
   - **贵人禄马到课**：主命年干之天乙贵人（甲戊庚牛羊、乙己鼠猴乡、丙丁猪鸡位、壬癸兔蛇藏、六辛逢马虎）、禄元（甲禄寅…癸禄子）、驿马（申子辰马在寅、寅午戌马在申、巳酉丑马在亥、亥卯未马在巳）出现于课四支为催贵，吉。
4. **格局亮点**：天干三朋/一气、地支一气、地支三合局（课支成申子辰水局等，局五行宜生扶坐山）。

## 六、董公择日（《董公選擇日要覽》，董德彰）

按**月建 + 建除十二神**给出逐日吉凶断语（断语中再按干支细化，如"甲子天赦""丙午正四废""煞入中宫"等）。脚本内置全书 12 月 × 12 神 144 条断语（`scripts/donggong_data.json`，据 laiboyee 繁体全文解析；三月收/开/闭三条 laiboyee 缺载，据文学城转录版补全），`riche` 自动输出：

- 当月当神的完整断语 + 命中本日干支的句子；
- 月令前奏：当月**三煞方位**（如"白露后三煞在东，寅卯辰方忌修造动土"）、四离四绝提示；
- 附录凶神月表自动比对：**往亡日**（忌出行赴任嫁娶）、**受死日**（忌百事）、**月厌大祸**、**冰消瓦解**、**勾绞**、**朱雀黑道**、**火星/黄沙/小红沙/天贼**等，命中即警示。

用法：选定候选日后跑 `riche`，看董公断语与凶神表是否有破；再以正体五行造命核扶山相主；两关皆过，再以紫白与宅盘旺衰定优劣。

## 七、按事项的择日要点（通用宜忌补充）

- **入宅/搬家**：喜成、定、开日；忌月破、岁破、四离四绝、冲宅主年支、冲坐山（脚本已自动判定）。民俗仪式细节（如先亮灯纳旺气、生旺时辰入门、忌从冲方扛重物入屋）可作话术参考，注明民俗。
- **婚嫁**（本模块延伸线，婚嫁以合婚为主、择日次之）：宜成/开日＋天德、月德、天德合、月德合、天恩、母仓、益后等吉神（名目见表下注）；忌月破、岁破、**往亡**（脚本凶神表已含）、正四废、红沙日；双方**本命年（值太岁）宜简礼**。⚠ 吉神的逐月取法（如"正月天德在丁…"）各通书略有出入，正式择日**以当年通书核对为准**，本 skill 不内置取法表。
- **动土装修**：忌月三煞方、土王用事期（通书核）、往亡、受死；配董公当月断语。

## 八、流年刑冲附注（地支六合/三刑）

- 地支**六合**：子丑、寅亥、卯戌、辰酉、巳申、午未——流年支与命支相合，传统作"有情"论。
- 地支**三刑**：寅巳申（恃势之刑）、丑戌未（无恩之刑）、子卯（无礼之刑）；辰午酉亥**自刑**——流年支与宅主命支相刑之年，配合冲煞提醒"该年注意口舌健康"，不作独立断语。

## 九、使用边界

- 本模块给**确定性要素**（四柱、紫白、建除、破日、冲煞、离绝）与**参考建议**；最终择日应结合宅主八字喜用、宅盘旺衰与地方风俗，吉神取法终以通书核对。
- 免责：择日属民俗传统，输出仅供文化研究参考。
