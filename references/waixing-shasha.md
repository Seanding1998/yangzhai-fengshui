# 外部形煞评估（峦头）

理气排盘之外，务必询问/检查外部环境（可让用户描述或拍照：窗景、楼前楼后道路、周边建筑、水体、高架、塔类设施）。形煞的强度取决于**距离、正对程度、大小**：正对门窗才有力，隔街远眺影响大减。

## 一、常见形煞速查

| 形煞 | 识别 | 传统主应 | 缓解原则 |
|---|---|---|---|
| 路冲（枪煞） | 长直道路/巷道正对门窗（丁字路口尤重） | 意外、是非、气冲不稳 | 玄关屏风挡、门口绿植/凸镜（民俗）；重点在"挡" |
| 反弓煞 | 道路/河流/天桥呈反弓形背抛本宅 | 破财、人情反复 | 窗帘常闭、厚重绿植挡 |
| 镰刀煞 | 高架桥/立交弧形贴楼 | 与反弓类似兼噪音 | 隔音密封+窗帘，实处化解 |
| 天斩煞 | 正对两栋高楼之间的狭窄夹缝 | 传统主血光、意外 | 避开正对角度，窗帘/绿植挡 |
| 壁刀煞 | 对面楼体侧面像刀切向本宅 | 切入何宫，看何星引动 | 遮挡为主 |
| 尖角煞 | 邻楼屋角、尖锐雕塑正对 | 是非、小伤 | 绿植盆栽缓冲 |
| 火形煞 | 高压塔、信号塔、尖顶建筑、烟囱正对 | 火患、心眼之疾、口舌 | 距离远(>百米)影响甚微，如实告知 |
| 割脚水 | 紧贴楼宇的道路/水流（贴脚而过） | 根基不稳、财难聚 | 现代临街房普遍，作提示 |
| 孤峰煞 | 本宅一枝独秀、四周低陷 | 无依、人丁缘薄 | 楼层过高(如30+层)常见，作提示 |
| 卷帘水 | 门前梯级向下直泄（含下坡路） | 财气下泄 | 门口地垫/玄关"聚气" |
| 反光煞 | 玻璃幕墙/大面积反光正照入宅 | 光污染扰神 | 窗帘、磨砂膜 |
| 声煞 | 主干道、铁路、机场、商铺噪音 | 神经衰弱 | 实用隔音为主，不玄学化 |
| 靠山缺失 | 坐后无楼无山（悬空、临谷） | 无贵人、丁弱 | 玄空上山下水局尤须坐后忌空；可高柜实墙补 |
| 污秽气口 | 正对垃圾站、医院后门、排污口 | 纳污气，健康受损 | 距离与风向判断强度 |

## 二、评估方法

1. 先问三件事：**坐向后与向首前**各是什么（楼/路/水/空地）；两侧是什么；有无塔类、夹缝、反弓。山水环境决定飞星"旺气是否用得上"。
2. **形理互参**：形煞落在哪个宫，就用该宫的山向星断引动之事（如壁刀切入 2·5 宫，流年二黑五黄再到，则健康问题显著化）。
3. 强度分级：正对本宅门窗(强)、斜对(中)、远处可见(弱)、看不见(不论)。
4. 大原则如实告知：**形煞先论"挡与避"**，其次才是化解物；城市住宅距离远时多数形煞不必紧张，避免制造焦虑。

## 三、给建议的边界

- 化解建议以"遮、挡、避、移"等物理手段为主；铜钱、八卦镜、水晶等民俗物品可提及，但必须注明"民俗传统做法，供参考，无科学实证"。
- 不以形煞恐吓用户；凡称"大凶"须同时给出距离/正对度等条件，并给可执行的缓解路径。
