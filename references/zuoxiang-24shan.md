## 二、坐向测量

1. **优先用度数**：让用户用手机罗盘/实物罗盘在屋内（多为客厅中央或阳台）测"面向屋外所得的朝向度数"。注意手机罗盘测的是**磁北**。
2. **磁偏角校正**：中国大部分地区磁偏角约西偏 2°–11°（如北京约 -7°、上海约 -5°、广深约 -2°~-3°、西部部分地区东偏）。用度数排盘时：真北 = 磁北读数 + 当地磁偏角（西偏为负）。若用户无法校正，直接用磁北度数排盘但须在报告中注明"未经磁偏角校正，坐向处于山内中间区域时影响不大，处于边界时必须校正"。
3. 也可用卫星地图/户型图结合道路走向估算朝向（精度约±5°，只能用于判断宫位，不宜用于判断兼向替卦）。

## 三、现代住宅的"以何为向"

两大法则并存，按以下顺序处理：

1. **问清并记录两类信息**：① 入户门（或单元门）朝向；② 主采光面/主阳台朝向。
2. 判断规则：
   - 传统独栋、自建房、门为主要开口的老房：**以门为向**。
   - 现代高层公寓：主流以**阳（主采光面/主阳台）为向**——纳气面最大。
   - 门向与阳向一致（同宫或同山附近）：无争议，直接定。
   - 门向与阳向不一致（如东西侧开门、南北阳台）：以纳气最旺的一面为向（通常是大阳台），**同时以门向另排一盘参看**，两盘结论一致处可信度高，不一致处如实告知用户存在争议。
3. 单元楼与户型：常用做法以**该户自身**的坐向排宅运盘（以该户纳气为准）；也有以整栋大楼坐向定盘、以户门看内局的做法。分析时默认用户型自身坐向，用户特别说明楼盘朝向差异大时两盘并看。
4. 别墅/自建房：以正门为向、背面为坐。

## 四、正向、兼向、替卦、空亡

设坐山中心角与实测坐向角的角度偏差为 d（|d| ≤ 7.5°）。分界采用**沈氏/中州派"每山正中九度"标准**（即正向 ±4.5° 为下卦，与替卦起星诀同属一个体系；另有流派以 3° 为界，见下注）：

| 偏差 | 定性 | 排盘 |
|---|---|---|
| d ≤ 4.5° | 正向 | **下卦盘**（沈氏/中州派标准；3°~4.5° 区间另有流派用替卦，保守可两盘参看，脚本会提示） |
| 4.5° < d ≤ 6° | 兼向 | **替卦盘**（沈氏起星） |
| 6° < d ≤ 7.5° | 大兼向 | 用替卦并显著提示不确定性；**d > 6.5° 已逼近两山交界线** |
| 正压两山交界线（±1°内，即 d > 6.5°） | 空亡线/骑线 | 传统认为不可用：务必复核坐向，报告中明确警示 |

补充规则（中州派）：同一卦宫内**阴兼阴、阳兼阳**可不替（等同下卦），阴阳互兼必须用替星；**出卦兼向**（偏向的邻山属另一宫）必用替卦且传统视为大忌。
3° 分界另有流传（一说与大玄空有关，原典出处未详）；本 skill 的替卦算法属沈氏体系，故分界统一取 4.5°，遇到 3°~4.5° 的坐向时在报告中说明流派差异。

- **出卦兼向**（偏向的邻山属于另一宫，如坐癸兼丑、坐庚兼戌）：传统视为"出卦空亡"，大凶勿用，务必建议用户复核或请专业人士实地复测。
- 替卦排法由 `scripts/fengshui.py` 自动完成（替星诀与顺逆法则已经中州派口诀与无常派实例双重验证），分析者只需解读。
- 座向不明时：先追问，不要猜。反复确认后仍无法定坐向的，输出"信息不足"模式。

## 五、常见易错点

1. 把"阳台朝向"当"坐向"：坐与向相差 180°。用户说"朝南"即**坐北朝南（坐子向午附近）**，宅卦按**坐**定。
2. 度数与"东西南北"混写：0°=北、90°=东、180°=南、270°=西。
3. 忽略磁偏角导致山向边界误判（尤其 5°/20°/35° 等边界附近）。
4. 手机横屏拿反：面向屋外测得的度数是"向"，背对的是"坐"。
