# 三元九运与宅运判定

## 一、三元九运总表

三元九运以干支纪年划分，每元 60 年、每运 20 年：

| 元 | 运 | 卦 | 起止年份 | 对照速记 |
|---|---|---|---|---|
| 上元 | 一运 | 坎 | 1864–1883 | 甲子年起 |
| 上元 | 二运 | 坤 | 1884–1903 | |
| 上元 | 三运 | 震 | 1904–1923 | |
| 中元 | 四运 | 巽 | 1924–1943 | |
| 中元 | 五运 | （寄坤/艮） | 1944–1963 | |
| 中元 | 六运 | 乾 | 1964–1983 | |
| 下元 | 七运 | 兑 | 1984–2003 | 改革开放初期商品房 |
| 下元 | 八运 | 艮 | 2004–2023 | 2004 年立春起 |
| 下元 | 九运 | 离 | 2024–2043 | **2024-02-04 立春起（当前）** |

- 各运以**立春**为界（如 2004-02-04 前建成属七运，之后属八运；2024-02-04 前属八运，之后属九运）。
- 精确立春时刻可用 sxtwl 查询；边界前后几日入伙的房屋需留意。
- 2044 年起进入上元一运（新的 180 年循环）。

## 二、房屋定运规则

1. **以建筑物落成（完工交付/入伙）时间定运**：这是主流做法。2004–2023 年建成 → 八运房；1984–2003 → 七运房；2024 年立春后建成 → 九运房。
2. 争议处理：
   - **建成时间与入住时间不同**：多数派以建成（封顶/落成）定运；亦有派以入伙（首次入住）定运。二者跨运时（如 2023 年底建成、2024 年入住），建议两盘参看，并以建成定运为主盘。
   - **整体改建/加建改变主体结构**：有"改建换运"之说（如拆除大半重建按新年份定运）；简单装修**不换运**。
   - 购买二手房：宅运仍按原建成年份，不因过户改变。
3. 无确切建成年份时：按小区建成年代推断（七运房 1984–2003、八运房 2004–2023），并明确告知用户这是推断。

## 三、当前九运（2024–2043）要点

- 九运对应**离卦**（中女、火、目、文明、电力/能源/文化传媒）。
- 一、九两运无当旺之山向：系旧题《青囊奥语》一系的通行说法（今人多归入沈氏玄空 48 局论——二至八运各 6/12 局旺山旺向，一、九运无），原典《青囊奥语》并无此句，引用时宜表述为"玄空旧诀云"。
- **九运下卦二十四山：没有旺山旺向局，也没有上山下水局**——每对坐向非"双星会坐"即"双星会向"（已程序枚举验证，与多家出版盘面一致）。分类如下（引擎输出应与此一致）：
  - 双星会坐（旺丁不旺财，坐后宜有实）：子山午向、癸山丁向、艮山坤向、寅山申向、卯山酉向、乙山辛向、辰山戌向、丙山壬向、未山丑向、庚山甲向、乾山巽向、亥山巳向。
  - 双星会向（旺财不旺丁，向首宜有明水/开阔）：午山子向、丁山癸向、坤山艮向、申山寅向、酉山卯向、辛山乙向、戌山辰向、壬山丙向、丑山未向、甲山庚向、巽山乾向、巳山亥向。
- **一运（1864–1883）与九运同理**：下卦 24 山全为双星会坐/会向，无旺山旺向、无上山下水（程序枚举验证），印证"一九两运无当旺之山向"。
- **五运（1944–1963）**：旺山旺向 12 局（子午、午子、癸丁、丁癸、丑未、未丑、卯酉、酉卯、乙辛、辛乙、辰戌、戌辰）＋上山下水 12 局（其余山向），是九运中旺山旺向最多的一运（程序枚举与通行资料一致）。
  - 双星会向要求向首有真实明水/开阔空间才旺财；双星会坐要求坐后有实。
  - 九运立向常退而求其次：求财选双星会向，求丁选双星会坐，配合峦头补救。
- 八运房（2004–2023）在九运中属"退运房"，旺星已退；但八运盘中的 8、9、1 组合宫位仍可取用（1 为未来生气），见 xuankong-feixing.md"旺衰"一节。
- 七运房（1984–2003）为衰死之宅，除非形峦极佳，一般需重点借流年旺气与内局调整。

## 四、地运与入囚（了解即可）

- 每个宅运盘有"地运"长短（约 20–160 年），到时旺气失效（"入囚"）。当旺之山星或向星落入中宫受困称"入囚"，其吉力难以发挥，需城门诀或流年旺气引动。
- 断宅时先报宅运，再报格局，最后才论各宫——**运是时间坐标，盘是空间坐标，流年是引动**。

## 五、给分析者的提醒

- 用户说"八运房/九运房"时，先用建成年份核实，不要照单全收。
- 同一栋楼里不同朝向的户型，宅运相同但飞星盘不同；不同期开发的小区可能跨运。
- 排盘一律调用 `scripts/fengshui.py`，禁止手工排盘或凭记忆报盘面数字。
